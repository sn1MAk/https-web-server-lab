# HTTPS Web Server Lab
## Тема
Розгортання веб-сервера Nginx, налаштування HTTPS із використанням OpenSSL та виведення у публічний доступ до локального веб-сайту через тунель ngrok.


## Мета роботи

- встановити та налаштувати Nginx;
- створити веб-сторінку;
- створити приватний ключ та SSL-сертифікат за допомогою OpenSSL;
- налаштувати HTTPS у Nginx;
- перевірити роботу веб-сервера в локальній мережі;
- забезпечити публічний доступ до локального сервера через ngrok;
- оформити результати лабораторної роботи та розмістити матеріали на GitHub.

### 2.2.Вер-сервер Nginx

**Nginx** — веб-сервер та reverse proxy, який може приймати HTTP та HTTPS-запити від клієнтів і повертати необхідні ресурси.

Схематично робота сервера має вигляд:
```
Клієнт
   ↓
HTTP / HTTPS
   ↓
Nginx
   ↓
/var/www/html/index.html
```

### 2.3.HTTP та HTTPS

**HTTP** використовується для передачі даних між клієнтом і веб-сервером.

**HTTPS** є захищеною версією HTTP та використовує протоколи TLS для забезпечення:
- конфіденційності
- цілісності даних
- автентифікації сервер
Під час використання **HTTPS** дані між клієнтом та сервером передаються через зашифроване **TLS**-з'єднання.

### 2.4.~~SSL~~/TSL-сертифікат

> [!note] 
> **SSL** - застарілий протокол розроблений у 1990-х роках, на зміну якому прийшов швидший та надійніший TSL у 1999-му році.

У роботі були створені:
```
/etc/nginx/ssl/server.key
/etc/nginx/ssl/server.crt
```
> [!warning]
> `server.key` — приватний ключ сервера. Він повинен зберігатися в секреті, тому у репозиторій не буде доданий.

`server.crt` — X.509-сертифікат, який містить відкритий ключ та інформацію про суб'єкта сертифіката, термін його дії та криптографічний підпис.

У роботі використовується *самопідписаний сертифікат(self-signed)*, тому браузер не довіряє та викидає червону табличку.

## 3.Розгортання веб-сервера

### 3.1.Встановлення Nginx
У Ubuntu WSL2 виконав оновлення списку пакетів та встановлення Nginx:
```bash
sudo apt update & sudo apt install nginx -y
```

Після встановлення перевіримо стан веб-сервера командою:
```bash
sudo systemctl status nginx
```
![sudo systemctl status nginx](https://github.com/sn1MAk/https-web-server-lab/blob/fa597aa3227ba3c41f43c4ed90970b0aef25c71c/screenshots/01-nginx-status.png)

Після встановлення **Nginx** став активним.
