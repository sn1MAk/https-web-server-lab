# ~~SSL~~/TLS
> Протокол SSL був створений ще у 1990-х роках та вважається застарілим, 
> на зміну йому прийшов швидший та надійніший TSL протокол у 1999-му році.
> Але інструменти по типу openssl та nginx з`явилися у період ssl, тому у народі закріпалася назва ssl

У лабораторній роботі для налаштування HTTPS на Nginx використовувався OpenSSL.

## Приватний ключ

Приватний RSA-ключ генерується командою:

```bash
sudo openssl genrsa -out /etc/nginx/ssl/server.key 2048
```

Параметр `2048` визначає довжину RSA-ключа в бітах.

## Самрпідписаний сертифікат 

Для створення X.509-сертифіката:
```bash
sudo openssl req -new -x509 \
-key /etc/nginx/ssl/server.key \
-out /etc/nginx/ssl/server.crt \
-days 30
```

> Сертифікат буде дійсний 30 днів(можна вказати більший період часу)

Сертифікат є самопідписаним, тому браузер йому не довіряє та буде показувати червону табличку.

## Перевірка сертифіката

Щоб переглянути інформацію про сертифікат потрібно використати команду 

```bash
openssl x509 -in /etc/nginx/ssl/server.crt -text -noout
```

## Перевірка TLS-з`єднання

Для перевірки команда:

```bash 
openssl x509 -in /etc/nginx/ssl/server.crt -text -noout
```

> Файли `server.key` та `server.crt` є секретом, тому до репозиторію не додаються.
